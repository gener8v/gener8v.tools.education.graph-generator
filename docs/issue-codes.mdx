# Issue codes

An invalid description reports each problem as an issue. `validate` and `createGraph` return the
issues. A component's fallback function receives them. The model tool and the export command print
them.

An issue is plain JSON data:

- `code`: one of the codes below.
- `path`: a JSON Pointer to the property, such as `/radius` or `/points/2/x`. An empty path is the
  whole description.
- `message`: a plain-English message that names the term and says what value would be accepted.
- Some issues also have `expected` (the kind of value accepted), `range`, `conflicts` (the paths of
  the other properties involved), `suggestion` (the closest term to an unknown one) or `allowed`
  (the accepted values).

## Print issues with formatIssue

An issue's `path` contains the caller's keys exactly as given. A key can contain line breaks or
text-direction characters that make a log line or a page show something misleading. Print issues
with `formatIssue` from `@gener8v/graph-generator/core`, never with `issue.path` directly.
`formatIssue` writes `path: message`. A path that is not a plain pointer is
quoted, clipped to 64 characters and escaped.

```ts
import { formatIssue, validate } from "@gener8v/graph-generator/core";

const result = validate({ type: "circle", radius: -3 });
if (!result.valid) {
  for (const issue of result.issues) console.log(formatIssue(issue));
}
```

It prints:

{/* sample: format-issue-radius */}

```text
/radius: radius must be a number between 0.001 and 1000000; got -3.
```

The issue itself:

{/* sample: issue-radius */}

```ts
{
  code: "out_of_range",
  path: "/radius",
  message: "radius must be a number between 0.001 and 1000000; got -3.",
  range: { min: 0.001, max: 1000000 },
}
```

## Limits and plain text

- `too_large`: a list longer than its `maxItems`, a description with more than{" "}
  <Limit name="DESCRIPTION_VALUE_LIMIT" /> values, or text longer than its limit. Titles, labels
  and names are at most <Limit name="CALLER_TEXT_LIMIT" /> characters and `unit` at most{" "}
  <Limit name="UNIT_TEXT_LIMIT" />, counted as code points. Longer text is rejected, never cut
  short. Each type's limits are in its input table on the **Vocabulary** page.
- `wrong_kind`: text with a control, line-break, text-direction or invisible character. The
  zero-width joiner and non-joiner and the emoji variation selectors are allowed. The
  **Vocabulary** page lists the characters.

Messages quote and escape these characters, so they show exactly what was supplied:

{/* sample: messages-plain-text */}

```text
/title: title must be plain text without control, line-break, text-direction or invisible characters; got "a\u202eb".
/title: title has 201 characters, more than the limit of 200; use fewer.
```

## Codes

The set of codes is fixed, and renaming or removing one is a breaking change. Your code can safely
test `issue.code`. `isIssueCode(value)` from `@gener8v/graph-generator/core` tells you whether a
value is a code, and `issueDocs[code]` gives the meaning shown below.
